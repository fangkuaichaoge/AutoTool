# Auto Tool

A native mod for Minecraft Bedrock (Android, arm64-v8a) on LeviLauncher /
preloader. It automatically selects the best hotbar tool for the block you are
mining.

---

## English

### What it does

- Picks the best tool in your hotbar when you start mining a block.
- Keeps re-evaluating while you hold the mining button and move the crosshair.
- Only switches when the candidate tool is better than the one you hold.
- Uses the game's normal hotbar selection, so the change is server-synced.

### Features

- Tool classes: pickaxe, axe, shovel, shears, sword, hoe.
- Tier ranking: wood, stone, iron, gold, diamond, netherite.
- No HUD, no settings, no log file.

### Usage

1. Import `AutoTool-1.0.0.levipack`.
2. Open the Mod Menu and enable **Auto Tool**.
3. Mine a block; the hotbar follows the block.

## 中文

### 简介

Minecraft 基岩版（Android，arm64-v8a）原生模组，运行于 LeviLauncher /
preloader。挖方块时自动切换到热栏中最适合该方块的工具。

### 功能

- 开始挖方块时自动选择热栏里最优的工具。
- 长按挖掘并移动准星时，会跟随目标重新选择。
- 只有候选工具比当前手持更好时才切换。
- 使用游戏正常的换槽方式，会同步到服务器。

### 工具与等级

- 工具类型：镐、斧、锹、剪刀、剑、锄。
- 材质等级：木、石、铁、金、钻石、下界合金。
- 无 HUD、无设置项、不写日志文件。

### 使用

1. 导入 `AutoTool-1.0.0.levipack`。
2. 打开 Mod Menu，启用 **Auto Tool**。
3. 对着方块挖掘，热栏会自动切换到对应工具。
